## FAQ

### Q: Is my data secure?
**A:** Yes. We use industry-standard encryption, MongoDB Atlas (AWS), and Amplify hosting. Your API credentials are encrypted and never exposed. Only you and your team can access your data.

### Q: How often is data updated?
**A:** Most data updates hourly. Some platforms (like Shopify) update near real-time. We pull fresh data each time you visit a dashboard.

### Q: Do I need technical knowledge?
**A:** No. Everything is designed for non-technical users. Setup guides are step-by-step with screenshots. AI will answer any questions.

### Q: Can multiple team members use it?
**A:** Currently single-user. Multi-user team accounts are planned for Q3.

### Q: What if I want data from another platform?
**A:** Tell us which platform. We can integrate most major tools (Pinterest, Google Shopping, Klaviyo flows, etc.).

### Q: Can I export data?
**A:** Yes. Export any chart as CSV/JSON. Copy metric data to spreadsheets. Integration with Google Sheets planned.

### Q: What happens if a platform's API changes?
**A:** We monitor all platform API changes and update automatically. You don't have to do anything.

### Q: Is there training?
**A:** Yes. Setup guides for each platform are built-in. AI chatbot answers questions. Team is available for support.

### Q: Can I integrate this with my existing tools?
**A:** Yes. We're building API access and Slack integration (planned for Q2).

### Q: What if I find a bug?
**A:** Report it and we'll fix it. Email support@devxlabs.ai or use the chat.
